Station 1 · Warm-up

Characters are numbers

Python's ord() turns a character into a number. chr() turns it back. Type a word and watch the running total. Python 1 checks a total like this.

Station 2 · Look

Look at the bytes before you decompile

A .pyc file is compiled, not encrypted. Its text and numbers are in the file as they are. Click a byte to see what it is. Use Find to search for text or for a whole number.

Click any byte.

Python stores a small whole number as the byte 69 or e9, then 4 bytes, lowest byte first. So 11 is e9 0b 00 00 00. Find shows every place a number's 4 bytes appear.

    Station 4 · Reverse a shift

    Shift letters forward and back

    Python 2 adds a fixed amount to each letter and wraps past z. To undo it, shift the other way by the same amount. Find the amount in the code or the bytes first.

    Station 5 · Reverse bit operations

    The Undo Machine

    Python 3 runs a number through shift, XOR and NOT. Each step has an inverse. Undo the last step first. This page uses Python's rules for whole numbers, so ~x is -(x + 1).
